Properties 설명

ㆍIn-game name : 블럭 이름

ㆍCreative inventory tabs : 특성

ㆍHardness : 경도 ( 블럭을 캐는 데 걸리는 시간 )

ㆍResistance : 저항 ( 폭발 저항력 )

ㆍLuminance : 0 ~ 15 ( 블럭이 내뿜는 빛의 밝기 )

ㆍLight opacity : 빛 통과 여부 ( 126 반투명, 255 완전 차단, 0 통과 )

ㆍHas gravity? : 중력 ( 모래, 모루처럼 떨어짐 / 커스텀 3D 블럭의 경우에는 지원하지 않음 )

ㆍIs replaceable : 물이나 잔디처럼 다른 블럭을 설치하면 사라지는 옵션

ㆍCustom drop : 파괴시 드롭되는 아이템 ( 설정 안 하면 블럭만 드롭됨 )

ㆍDrop amount : 아이템 드롭되는 양

ㆍUse custom loot table for drops : 체크하면 전리품 테이블의 영향만 받음

ㆍCreative pick item : 블럭을 마우스 휠 클릭하면 나오는 아이템

ㆍTool able to destroy it : 블럭을 부술 수 있는 도구

ㆍRequires the correct tool for drops? : 적절한 도구가 있어야 아이템이 나오는지 여부

ㆍVanilla sound set : 블럭 사운드 설정 ( Custom sound set 체크하면 커스텀 사운드로 설정 )

ㆍBreak sound : 파괴 사운드

ㆍFall sound : 착지 사운드

ㆍHit sound : 블럭을 두드릴때 나는 소리

ㆍPlace sound : 블럭 설치 사운드

ㆍStep sound : 블럭위를 걸을 때 소리
